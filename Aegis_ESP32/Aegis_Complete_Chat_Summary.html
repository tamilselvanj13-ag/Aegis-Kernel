1. EXECUTIVE PROJECT OVERVIEW

The Aegis Project is an ultra-low-power, hardware-isolated intrusion detection sentinel designed to detect advanced Linux host exploits in real time. Modern cyber threats frequently employ in-memory fileless executions (memfd_create), dynamic library hooking (LD_PRELOAD), reverse TCP shell sockets, and high-entropy packed code that evade conventional disk-centric antivirus scanners.

Aegis decouples detection from the host platform by streaming 8-dimensional kernel process telemetry across a dedicated physical USB/UART bridge to an external ESP32 microcontroller. The coprocessor executes an ensemble dual-engine: a 55-node static Decision Tree ($1.2~\mu\text{s}$ latency, 92.46% validation accuracy) and a continual learning perceptron equipped with a 16-slot Experience Replay Buffer and on-chip Momentum Stochastic Gradient Descent (SGD). All decisions are reflected on an I2C OLED display, active piezo buzzer siren, and visual status LEDs with zero heap fragmentation.

Key Architectural Pivot

The project originally contemplated a complex multi-board architecture consisting of a Raspberry Pi 4, Raspberry Pi Pico coprocessor, high-speed SPI bus, logic analyzers, and custom eBPF in-kernel tracepoints with a bill of materials exceeding $150. During early development, the architecture successfully pivoted to a streamlined, cost-effective single ESP32 node (~₹500 / $6) fed via asynchronous psutil polling of the Linux /proc filesystem. This eliminated severe hardware complexity while retaining complete out-of-band physical isolation.

Phase 5: Deep Debugging — The "Everything Safe" & "Safe False Positive" Bugs (Prompts 44 – 48)

Issue 1: Why did every command register as SAFE?

  • Root Cause A: windows_serial_bridge.py was prepending EVAL to lines that already started with VEC, sending EVAL VEC 0,83... to the ESP32. The firmware treated the string "VEC 0,83..." as a literal command line, found no exploit keywords, and evaluated it as SAFE.
  • Root Cause B: At WSL boot, ~20 background system daemons (/init, udev-worker, login, bash) flooded in within 1 second. With g_auto_adapt = true, the 16-slot buffer auto-consolidated with target 0.0, driving the bias to -6.0 and saving corrupted weights to Flash NVS.
  • Root Cause C: The 92.46% accurate Decision Tree (predict_aegis_8d) was never being called in the firmware evaluation loop.
  • Fix: Built unified evaluate_telemetry_vector() combining the Decision Tree, Continual Perceptron, and Threat Severity Scoring; disabled g_auto_adapt by default; enforced #define AEGIS_MODEL_VERSION 4 to auto-wipe corrupted Flash on boot; and made the bridge send VEC cleanly with live bidirectional response printing.

Issue 2: Why did python3 -c "print('Hello Kernel Sentinel'); ...' flag as SUSPICIOUS?

  • Root Cause: Inline Python command punctuation (quotes, semicolons, brackets) yielded Shannon entropy $H(s) = 4.24$, tripping the static decision tree's threshold ($> 3.6989$).
  • Fix: Implemented a benign syntax exemption rule in evaluate_telemetry_vector(): when a command has zero threat flags (not in /tmp, not root, not fileless, no reverse shell, not orphaned, not web child) and short/medium length ($< 120$ chars) with low threat score ($\le 30$), punctuation entropy is classified as SAFE.

5. MACHINE LEARNING & MATHEMATICAL FORMULATIONS

A. 8-Dimensional Process Telemetry Feature Vector

x = [ x_temp,  x_len,  x_ent,  x_root,  x_web,  x_dead,  x_memfd,  x_ld ]^T
  • x_temp (Binary): 1 if binary executes from volatile paths (/tmp, /var/tmp, /dev/shm); 0 otherwise.
  • x_len (Integer / Normalized): Command line character length (normalized as $x_{ ext{len}} / 50.0$).
  • x_ent (Float): Shannon Information Entropy of command string ($1.50 - 6.20$). Baseline $\mu_{ ext{ent}} = 3.15$.
  • x_root (Binary): 1 if process UID == 0 (superuser privileges); 0 otherwise.
  • x_web (Binary): 1 if process ancestry originates from a web daemon (nginx, apache2, gunicorn).
  • x_dead (Binary): 1 if parent process PPID is dead or terminated (orphaned process).
  • x_memfd (Binary): 1 if executing via anonymous fileless memory descriptors (memfd_create).
  • x_ld (Binary): 1 if dynamic linker injection (LD_PRELOAD) or reverse shell redirection (/dev/tcp, >&, 0>&1) detected.

B. Shannon Information Entropy

H(s) = - sum_{k=1}^{K} (n_k / N) * log2(n_k / N)

Where $N$ is the string character length, $K$ is the number of distinct character classes, and $n_k$ is the frequency of character $k$. Plain text daemons exhibit entropy $2.8 - 3.4$; base64-packed or encrypted payloads exceed $4.5$.

C. Continual Learning SGD & Experience Replay

z = b + sum_{i=1}^{8} w_i * x_norm_i ,      P(anomaly) = 1 / (1 + exp(-z))
v_i^(t) = gamma * v_i^(t-1) + (1 - gamma) * (y - P) * x_i
w_i^(t) = w_i^(t-1) + eta * v_i^(t)

Where learning rate $\eta = 0.04$ and momentum factor $\gamma = 0.85$. Samples are queued into a 16-slot circular buffer in static SRAM. Batch consolidation executes in $38~\mu\text{s}$ with 0 heap allocation.

D. Heuristic Threat Severity Scoring (0 – 100)

S(x) = S_base + 40*x_memfd + 35*x_web + 20*x_temp + 20*x_ld + 10*x_root + Delta_H(s) + Delta_len
